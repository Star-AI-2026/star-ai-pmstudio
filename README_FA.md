# اصلاح پنجره Settings برای Liquid Glass جدید

این Patch فقط دو فایل را تغییر می‌دهد:
- `src/styles.css`
- `src/components/star/SettingsDialog.tsx`

## علت مشکل قبلی
در حالت New، پس‌زمینه پنجره تنظیمات به `bg-black/5` تبدیل شده بود؛ در نتیجه محتوای صفحه اصلی بیش از حد واضح از پشت پنجره دیده می‌شد. همچنین انیمیشن پنل از CSS `filter` استفاده می‌کرد که می‌تواند با نمونه‌برداری `backdrop-filter` تداخل داشته باشد.

## اصلاح این نسخه
- لایه بیرونی فقط کمی صفحه را تیره می‌کند (`bg-black/20`) و خودش Blur ندارد.
- Blur قوی روی سطح واقعی پنجره تنظیمات اعمال می‌شود (38px دسکتاپ، 30px موبایل).
- انیمیشن ورود و خروج پنل دیگر `filter: blur()` اعمال نمی‌کند تا شیشه بتواند محتوای پشت خودش را درست محو کند.
- Old version بدون تغییر می‌ماند.
- `public/version.json` داخل Patch نیست و نباید تغییر کند.

## اعمال
دو فایل را در همان مسیرهای پروژه جایگزین کن، سپس Build و Deploy بگیر.
