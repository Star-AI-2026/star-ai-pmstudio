Star-AI UI language patch

Changes:
- The Check for updates button and Update Checker dialog are English-only in every app locale.
- Arabic (العربية) was added as an interface language in Settings > Language.
- Arabic UI uses RTL layout and persists as the selected interface language.
- Arabic language is accepted by the public chat and image-generation API request schemas.
- Arabic greeting and experimental Beta error messages were added.

This is a source project archive. Replace your project files with these source files and run your normal build/deploy workflow. Review your own latest repository changes before overwriting them.
